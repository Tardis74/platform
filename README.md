# Лицейская платформа автоматизации

## Описание
Веб-платформа для автоматизации взаимодействия между родителями, учениками, педагогами и администрацией лицея. API-first архитектура, единая точка входа.

## Требования
- PHP 7.4+
- MySQL 5.7+
- Apache с mod_rewrite
- Composer

## Установка и настройка

1. **Клонируйте репозиторий** в папку проекта (например, `C:/xampp/htdocs/school`).

2. **Настройте виртуальный хост** (например, `school.local`), указав `DocumentRoot` на `public/`.

3. **Установите зависимости Composer**:
   ```bash
   composer install
